# Extension Download Hub

A simple website to host and share Chrome extensions.

## Features
- 📤 Upload ZIP files
- 📥 Direct download link
- 🔗 Shareable links
- 💾 Browser-based storage (no server needed)
- 📱 Mobile responsive

## How to Use

1. Open `index.html` in browser
2. Upload your extension ZIP file
3. Share the generated link with others
4. Users can download and install

## Installation Instructions

### For Chrome:
1. Download the ZIP
2. Go to `chrome://extensions/`
3. Enable Developer Mode
4. Drag & drop ZIP file

### For Edge:
1. Download the ZIP
2. Go to `edge://extensions/`
3. Enable Developer Mode
4. Load unpacked extension

## Note
All files are stored in your browser's localStorage. No server-side storage.
